# Mira

Общая доска для занятий английским. Репетитор раскладывает PDF и картинки, пишет заметки и рисует. Ученики в той же комнате видят это сразу, видят курсоры друг друга и могут смотреть на доску глазами другого человека.

Сервер на Python (FastAPI и WebSocket) хранит комнаты, файлы и рассылает правки. Холст работает в браузере на React.

## Роли

В `.env` два входа:

- репетитор создаёт комнаты, видит пароль каждой и может его сменить;
- ученики входят одним общим логином, комнаты не создают и пароли не видят.

Дальше репетитор задаёт каждой комнате свой пароль. Ученик Артём знает пароль только своей комнаты и попадает только в неё. Имя, которое он напишет при входе, видно у его курсора.

## Запуск

Нужны Docker и Docker Compose v2.

```bash
cp .env.example .env
```

В `.env` замените пароли и `SECRET_KEY`:

```bash
python3 -c "import secrets; print(secrets.token_urlsafe(32))"
```

```bash
docker compose up -d --build
```

Приложение откроется на `http://АДРЕС:8080` (порт меняется через `PORT` в `.env`). Комнаты и загруженные страницы лежат в томе `mira_data`.

Если перед приложением стоит HTTPS, поставьте `COOKIE_SECURE=1` и перезапустите контейнеры. Иначе браузер не запомнит вход.

## На доске

Колесо мыши двигает доску, колесо с Ctrl (щипок на тачпаде) приближает. Пробел временно включает руку. PDF режется на страницы, максимум 30 страниц и 40 МБ. Картинку или PDF можно перетащить на доску или вставить из буфера.

«Смотреть» у имени в списке справа переносит ваш экран туда, куда смотрит этот человек. Свой сдвиг или масштаб открепляет слежение.
